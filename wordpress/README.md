# WordPress Сервис 101

Собственная тема сохраняет текущую вёрстку. Плагин `service101-catalog` хранит каталог отдельно от оформления и обеспечивает импорт/экспорт `.xlsx`.

Содержимое `wp-content` устанавливается в отдельный WordPress. Ядро, `wp-config.php`, рабочая медиатека и зависимости Composer не хранятся в Git. В плагине выполнить `composer install --no-dev --prefer-dist --optimize-autoloader` с PHP 8.3+.

Тестовая площадка: `https://wp-stage.сервис101.рф/`, отдельная папка `service101-wp-stage/public_html` и отдельная база. Доступ закрыт HTTP-аутентификацией, индексация и исходящая почта отключены. Основной домен продолжает обслуживать прежнюю версию.

Beget: команды CLI запускать через `/usr/local/bin/php8.3 /usr/local/bin/wp-cli.phar`. Обёртки `wp` и `composer` по умолчанию используют другие версии PHP. Системный Composer 1 устарел; для этой площадки отдельно установлен Composer 2.10.3 в приватной папке аккаунта, без изменения системных инструментов.

Проверка плагина: `wp eval-file wordpress/tools/test-catalog.php --user=<администратор каталога>`. Скрипт разрешён только для staging: проверяет повторный импорт, отсутствие дублей, частичную правку точной цены, устаревший предпросмотр, откат и экспорт/повторное чтение Excel. Рабочая книга в приватной папке сервера.

Перед переключением основного домена обязательна отдельная приёмка владельцем. Создание staging само по себе не является переключением.

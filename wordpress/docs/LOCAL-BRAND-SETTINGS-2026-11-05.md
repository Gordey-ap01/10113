# WordPress в Local и настройки брендов — Gordey_ap01

Дата: 5 ноября 2026. Ветка: `feature/local-brand-settings-20261105`.

## Рабочий сайт

В программе **Local** создан сайт **Service101 — Gordey_ap01**:

- Сайт: <http://service101.local/>
- Бренды: <http://service101.local/wp-admin/admin.php?page=s101-brands>
- Вход: выбрать сайт в Local и нажать **WP Admin**. Включён штатный One-click admin для существующего локального администратора `gordey_local` (имя в списке — `Gordey_ap01`). Его прежний пароль также сохранён.
- Окружение: WordPress 7.1.4, PHP 8.3.36, MySQL 8.0.35, nginx 1.26.1.

Корень Local: `%USERPROFILE%/Local Sites/service101-gordeyap01/app/public`.

Тема `wp-content/themes/service101` и плагин `wp-content/plugins/service101-catalog` подключены через NTFS junction к соответствующим каталогам `D:/101/10113-wordpress/wordpress`. Поэтому Local исполняет код из рабочего дерева Git. Для работы с Git открывать репозиторий `D:/101/10113-wordpress`, а не создавать новый репозиторий в папке Local.

Репозиторий: <https://github.com/Gordey-ap01/10113>. Данные, изменённые через админку, находятся в базе Local; Git хранит исходники. Копию базы нужно сохранять отдельно от коммитов.

После проверки перезапуска Local прежние контейнеры WordPress и его базы проекта `service101-recovery-20261102` остановлены. Local работает без них. Отдельная исходная статическая версия остаётся на <http://127.0.0.1:8184/> в Docker.

## Настройки бренда

Путь: **Каталог → 2. Бренды → Изменить**.

| Поле | Где используется |
| --- | --- |
| Короткое описание | Под названием устройства, у всех моделей бренда во всех его категориях |
| Типовой ремонт | Срок в карточке устройства, например `от 30 мин` |
| Гарантия | Срок в карточке и повтор гарантии над прайсом, например `до 12 мес` |

Поле короткого описания убрано из формы категории. Выбор категории или модели больше не подменяет описание бренда. Индивидуальные описания моделей сохранены в данных и Excel, но этот общий текст карточки теперь берётся из бренда.

Пустые поля используют значения: `Диагностика и согласование стоимости до начала ремонта.`, `от 30 мин`, `до 12 мес`.

При переносе у 19 брендов сохранён прежний текст единственной подходящей категории. Для Apple, Honor, Huawei, Infinix, Lenovo, Nintendo и Sony нельзя было однозначно выбрать один прежний текст: они пока используют нейтральное описание. Его можно заменить в бренде. Исходные тексты категорий и моделей не удалены.

Одноразовый перенос на другом staging-экземпляре:

```sh
wp eval-file wordpress/tools/migrate-brand-presentation.php --user=<administrator>
wp eval-file wordpress/tools/migrate-brand-presentation.php apply --user=<administrator>
```

Первый вызов показывает план. Второй записывает только отсутствующие описания брендов; существующие значения, включая явно очищенные, сохраняются.

## Сохранность и проверка

Свежий снимок перед переносом: `D:/101/local-migration-2026-11-05/backup`.

Сохранены 118 устройств, 1941 строка цен, 52 услуги, 28 пакетов импорта, 12 заявок, 26 брендов, 6 категорий, 138 записей WordPress и 6 записей медиа. Все 12 файлов uploads совпали по SHA-256. Содержимое устройств, цен, услуг и истории импорта совпало; у заявок изменён только локальный домен в URL страницы.

- Проверки PHP: 46 успешных в изолированной Docker-базе, 36 в отдельной базе на PHP Local.
- HTTP-проверки на копии базы: 15 успешных, включая сохранение формы, повторное чтение, общий текст Apple у iPhone и MacBook, независимость Samsung, экранирование и отказ при неверном nonce.
- На основном Local-сайте: 127 страниц и 27 ресурсов вернули HTTP 200 после остановки старого WordPress в Docker.
- Экспорт и чтение Excel проверены на всём каталоге в Local.
- Сохранены staging-preview черновиков, запрет индексации и подавление исходящих писем. nginx запрещает исполнение PHP в uploads; контрольный файл получил HTTP 403 и был удалён.

Карточка iPhone открыта в настоящем встроенном браузере; главная проверена по HTTP. Кнопка Local открыла админку в Chrome, но дальнейшая автоматизация окна Chrome остановлена инструментом из-за невозможности подтвердить URL. Проверки сохранения после этого выполнялись через локальный HTTP-интерфейс на отдельной копии базы; ручная браузерная проверка нажатия «Сохранить» не заявляется.

Доказательства и журналы: `D:/101/local-migration-2026-11-05/verification.json`, `http-brand-tests.json`, `local-tests.json`, `docker-tests.json`.

Архивы, SQL и файлы доступа остаются вне Git. Публичный хостинг не изменялся; исходный статический `index.html` не менялся.

Формат резервного импорта Local (`wp-content` и SQL) описан в [официальной инструкции Local](https://localwp.com/help-docs/getting-started/how-to-import-a-wordpress-site-into-local/). Входные значения полей очищаются функциями WordPress, включая [sanitize_textarea_field](https://developer.wordpress.org/reference/functions/sanitize_textarea_field/), а вывод экранируется.

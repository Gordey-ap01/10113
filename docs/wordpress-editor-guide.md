# Как обновлять каталог Сервис 101

На тестовой площадке главный сайт, страницы организаций и каталог используют прежний дизайн. Просмотр [wp-stage.сервис101.рф](https://wp-stage.xn--101-eddot8cge.xn--p1ai/) открыт без логина и пароля. Кнопка «Выбрать ремонт» ведёт к направлениям, а карточки направлений — к устройствам и ценам. Все 117 исходных моделей сохранены как черновики; для тестового поддомена включён их публичный предпросмотр. Для редактирования требуется вход в WordPress.

## Обновить данные через Excel

1. В WordPress откройте **Каталог → Импорт Excel** и нажмите **Скачать Excel с текущими данными**. Перед каждой новой серией правок скачивайте свежую книгу.
2. На листе **Устройства** модель занимает одну строку. Здесь находятся название, бренд, категория, описание и ссылки на фотографии.
3. На листе **Услуги и цены** каждая строка — отдельная работа для устройства. Код в столбце A связывает её с моделью; название в столбце B подставляется автоматически.
4. Измените нужные данные и сохраните файл в формате `.xlsx`.
5. Загрузите книгу в том же разделе и нажмите **Проверить книгу**. Пока вы не применили пакет, данные сайта не меняются.
6. Прочитайте отчёт, включая старые и новые цены, ошибки и предупреждения. Если всё верно, нажмите **Применить проверенные изменения**.

Не меняйте заголовки в строке 7. Данные начинаются со строки 8. Постоянные коды связывают записи; изменение названия не требует нового кода. Регистр кодов не различается.

## Добавить модель

Добавьте строку на листе «Устройства» и задайте свободный код, например `D0118`. Заполните название, категорию и бренд. Выберите **Черновик**. Для существующей категории используйте её прежний «Код категории»; при полностью новой категории он может быть сформирован из названия. Служебные адреса уже существующих моделей менять нельзя.

На листе цен скопируйте строки похожего устройства и замените код устройства на новый. Сохраните общие коды услуг, если это те же работы; измените цены и сроки. Для новой работы задайте свободный код услуги. Один общий код услуги должен иметь одинаковое название у всех моделей.

Без Excel: **Каталог → Добавить устройство**. Там можно скопировать набор работ существующего устройства, добавить строки и проверить изменения перед сохранением.

## Фотографии и цены

Вставляйте прямую HTTPS-ссылку на файл JPG, PNG или WebP, без пароля и ограничения доступа. Картинка загрузится в медиатеку WordPress. Вложения внутрь ячейки Excel не используются. Исходный каталог содержит 6 общих картинок категорий; индивидуальные фото можно добавить позже.

Стоимость работ и стоимость с деталью — разные столбцы, их не нужно складывать. Числа вводите без знака ₽. Типы **От**, **Бесплатно**, **По запросу**, **Ориентир** и **После диагностики** выбирайте из списка. При «Бесплатно» цена равна нулю, при «По запросу» и «После диагностики» числовая сумма отсутствует.

Пустое поле существующей записи сохраняет прежнее значение. Для удаления необязательного значения напишите `[очистить]`. Пропущенная или удалённая из Excel строка не удаляет данные сайта. Чтобы убрать услугу, выберите **Скрыть** в её действии.

## Публикация и восстановление

После проверки содержимого модели замените **Черновик** на **Опубликовать** и примените пакет. Для снятия с публикации используйте **Скрыть**. Сейчас тестовый сайт показывает весь каталог в режиме предпросмотра, включая неопубликованные модели; статусы публикации при этом не меняются. Запрет индексации действует на весь тестовый поддомен. На будущей рабочей установке такой предпросмотр отключён: посетители видят только опубликованные модели.

В **Каталог → История изменений** можно открыть последний применённый пакет и восстановить состояние до него. Восстанавливается весь каталог. Если после пакета уже были другие изменения, автоматическое восстановление блокируется, чтобы сохранить более поздние правки.

Если книга устарела, скачайте новый экспорт и перенесите в него свои изменения. Не удаляйте служебную версию файла для обхода этой проверки.

Лимиты книги: 8 МБ, 1000 устройств, 5000 строк услуг. На тестовой площадке заявки проверяют форму, но реальные письма не отправляются. Основной домен продолжает работать отдельно.

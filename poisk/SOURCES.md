# Получение данных поставщиков

Автор: **Gordey_ap01**. Проверено 16 ноября 2026 года реальными запросами без оптовых кабинетов.

| Источник | Рабочий способ | Подтверждённые поля | Ограничение |
| --- | --- | --- | --- |
| [TAGGSM](https://taggsm.ru/) | HTML выдачи `route=product/searcho`, затем карточки товаров | Название, ссылка, артикул, цены, наличие по городам | Поиск нечёткий: соседние модели отсекаются приложением. Проверяется Хабаровск. |
| [MOBA Хабаровск](https://khabarovsk.moba.ru/) | HTML `/catalog/?q=...&page=...` | Название, артикул, обычная и скидочная цена, наличие, поступление | В HTML есть скрытые шаблоны: они исключены. Поступление в магазин не считается доставкой клиенту. |
| [DVSOTA](https://parts.dvsota.ru/) | HTML `/catalog/?q=...` | Название, видимый артикул, цена, качественная оценка наличия | Внутренний schema SKU отличается от видимого артикула. Цена бывает не опубликована. Точное количество не сообщается. |
| [GreenSpark](https://green-spark.ru/) | Данные `__NUXT_DATA__` внутри HTML `/search/`; для поиска по артикулу — проверка карточки | Название, ссылка, цены с названием тарифа, наличие, фактический магазин | Данные поиска не содержат артикул; он уточняется в карточке. Анонимный сайт часто выбирает Москву. |

Основной путь уже реализован: запрос мастера → чтение сайтов → нормализация модели/качества/наличия → независимые результаты каждого поставщика. Кеш пять минут; показано время получения данных. Продолжение выдачи загружается явно кнопкой. Недоступный источник не мешает остальным.

У GreenSpark подтверждена анонимная JS-cookie проверка. Воспроизводится фиксированный алгоритм страницы, без запуска стороннего JavaScript и без доступа к пользовательским cookies браузера. Защищённые кабинеты, CAPTCHA и ограничения доступа не обходятся.

## Другие варианты

1. **Публичные JSON-ответы и встроенные данные.** Предпочтительны, когда содержат те же данные, что интерфейс. У GreenSpark встроенный JSON уже используется. Публичная база `/local/api` обнаружена, но отдельный подтверждённый универсальный каталог API не заявляется.
2. **Страницы товаров.** Дополняют выдачу недостающим артикулом и характеристиками. Приложение ограничивает дополнительные проверки GreenSpark тремя кандидатами на точный артикул, чтобы не превращать поиск в массовый обход.
3. **Sitemap и каталоги.** Подходят для обнаружения ссылок и периодической индексации, но не гарантируют актуальную цену и наличие. У DVSOTA robots содержал ссылку на чужой sitemap — она не используется. Массовый обход поисковых URL не нужен.
4. **Анонимный браузер.** Резерв, если поставщик перенесёт данные в клиентский JavaScript. Требует отдельного процесса и больше ресурсов, чем текущий PHP-хостинг. Сейчас для четырёх источников не требуется.
5. **XLS/CSV/XML-прайсы и официальный API.** Могут дать более полный каталог и договорные цены. Это дополнительный вариант после появления кабинетов или договорённости; для текущего рабочего поиска не обязателен.
6. **Авторизованный кабинет.** Нужен только для персональных условий мастера. Его наличие у «Сервиса 101» пока не подтверждено. Текущие цены — анонимные цены сайтов, скидочные тарифы показаны отдельно с оговоркой об их применимости.

Полную подтверждённую доставку до Комсомольска-на-Амуре нельзя получить из полей, которых поставщики не публикуют. Для этого понадобится источник тарифов и сроков перевозчика либо данные поставщика по конкретному адресу/заказу. До появления этих данных стоимость и срок остаются неизвестными; они не заменяются догадкой.

## Проверенные примеры

- Экран iPhone 12: все четыре источника возвращают реальные предложения. В выдаче сохраняется разница между iPhone 12, mini, Pro и Pro Max; совместимые 12/12 Pro принимаются для обеих моделей.
- MOBA `LCD-PMI120-CP-B-HOD`: одна деталь, 3 100 ₽, Хабаровск.
- GreenSpark `GS-00024042`: одна деталь, 5 120 ₽ по тарифу «Столичный», другой тариф 3 950 ₽; магазин Москва, ТК «Митинский», наличие «Мало».

Это примеры проверки на указанную дату, а не сохранённый прайс для интерфейса. В интерфейс поступают только ответы текущих запросов или их явно отмеченный краткосрочный кеш.
